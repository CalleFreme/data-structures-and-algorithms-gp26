# Week 5 Tuesday — Measure Before You Optimize

Use alongside Lab 7.

## 1. Prediction

- What operation do you predict dominates the baseline workload?
- What evidence would prove or disprove that prediction?

## 2. Baseline

- Record input size/workload.
- Record at least three timing runs or the supplied aggregate.
- Record deterministic counters.
- Confirm correctness tests pass.

## 3. Hypothesis

- Write **one** change you expect to help.
- Name the operation it should reduce.
- State one trade-off you expect.

## 4. After

- Repeat the exact same workload.
- Record timing and counters.
- Confirm tests still pass.

## 5. Conclusion

- Did the change help?
- Which evidence supports that conclusion?
- Was the original prediction correct?
- Would you keep this change in production code? Why or why not?
