# AI as a Learning Tool

AI assistance can be useful when it increases your understanding.

Helpful examples:

- “Do not solve this. Ask me questions that help me identify the invariant.”
- “Give me edge cases I should test, without writing the implementation.”
- “Challenge my complexity analysis.”
- “Help me design a debugging procedure before suggesting a fix.”
- “Explain this error message in terms of what my code is doing.”

Less useful for learning:

- asking for a complete lab/assignment solution;
- copying an implementation you cannot explain;
- generating an analysis after the fact and submitting it as your own reasoning.

You remain responsible for understanding and being able to explain the code and decisions you submit.
